# Arcturius Cycle —— 半年周期发布

每半年一场的技术发布，档期随学校假期：**暑假一场（Solstice 场）、寒假一场（Equinox 场）**。内容固定三段：

- **Shipped** —— 做了什么（各仓 Release 汇总，按扇区叙述）
- **Numbers** —— 做得怎么样（stars / traffic / releases / contributors 等 gh 自动拉取）
- **Next** —— 要做什么（半年 roadmap，落成 GitHub Milestones，到期日 = 下期发布）

## 命名约定

| 项 | 规则 | 示例 |
|---|---|---|
| 全称 | `Arcturius Cycle <罗马数字> <场次词>` | Arcturius Cycle IV Solstice |
| 简写 | `ac<期号><场次首字母小写>` | `ac4s` |
| 暑假场 | Solstice，记 `s` | `ac4s` |
| 寒假场 | Equinox，记 `e` | `ac5e` |

- 期号**按场次递增**：一场一个号，`Cycle` 即半年周期本身。
- 场次词仅作季节记号，**不对应天文历法**——Solstice / Equinox 为既定标签，不背书二至二分，亦不声称与夏至 / 冬至日期重合。
